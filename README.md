# photoghaphers-website (web)

Учебный курсовой проект - Сайт-визитка фотографа

Архивный проект | 2022 год | HTML CSS JAVASCRIPT

---
## О проекте

Разработано как учебный проект для:
- Знакомства с версткой
- Работы с базой данных

## Возможности

- Расчет стоимости сессии
- Панель администратора для добавления изображений
- Формы для записи и вопросов
